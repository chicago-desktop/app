                        ACCESSORIES
                        ===========

The small programs that came with the system. On this desktop most of them
are real, and the ones that are real are not imitations - they are written
here, as modules, each in its own repository.


REAL, AND IN THE START MENU
---------------------------

  NOTEPAD         Opens a file from any drive on C:, edits it, saves it
                  back. It titles its window with the file name and a plain
                  hyphen, as it should. It opens .txt, .ini, .log, .md,
                  .json, .yaml, .lua and a dozen more, because it declares
                  those extensions itself and the file type registry is
                  assembled from what programs declare.

  CALCULATOR      Standard view, the keys in the right places.

  MINESWEEPER     A real Minesweeper: the first click is never a mine, the
                  counter counts down, and the face is a face.

  PAINT           Not yet. The picture viewer opens .png, .gif and .jpg and
                  draws them one pixel to one pixel, but nothing here
                  paints.

  CLOCK           In the tray, at the right of the taskbar, and a click on
                  it opens Date/Time - the same dialog, with the calendar.

  MS-DOS PROMPT   A real terminal in a window. Administrator rights needed.


WHAT IS NOT HERE
----------------

  HYPERTERMINAL   For talking to a modem, which see.
  DIAL-UP NETWORKING, PHONE DIALER, CD PLAYER, SOUND RECORDER, VOLUME
                  All of them need hardware this system does not have.
  WORDPAD         Notepad with a font menu. Perhaps one day.
  CHARACTER MAP   Every character is already available; this is a terminal.
  BACKUP          Nobody used it in 1995 either.
