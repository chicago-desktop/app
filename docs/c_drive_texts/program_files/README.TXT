                        PROGRAM FILES
                        =============

The folder that was new. Before it, a program went into a directory of its
own with a name of eight letters - WINWORD, PHOTOSHP, NETSCAPE - and the
folder with the long name, with a SPACE in it, was the sign that things had
changed.

Nothing here is a program. The programs on this desktop are modules in a
registry, and there is no directory on any disk where they live: the Start
menu is built from the registry every time it opens, and Add/Remove Programs
edits a folder of declarations, not a folder of files.

So this is a folder of what programs left behind, which in 1995 was most of
what a disk held anyway.

  Accessories\        The small programs that came with the system, and
                      which of them are real here.
  Common Files\       The folder every installer wrote into and no
                      uninstaller ever cleaned out.
  Online Services\    How a machine got to a network, and what it sounded
                      like.
  Chicago Desktop\    This desktop, as an installed program would have
                      described itself.

A note on the space in the name: this folder is a filesystem the application
declares, and the entry that declares it is called `program_files`, because
an entry name cannot have a space in it. The caption you are reading it
under - "Program Files" - is `meta.title` on that entry, the same field the
Control Panel uses for its own name. The address and the caption are
different things, and this folder is where the difference finally mattered.
