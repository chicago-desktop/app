                      THE COMMAND FOLDER
                      ==================

In the original this held the commands that survived the move from the
command line: DELTREE, XCOPY, EDIT, SCANDISK, CHOICE, MEM, and a handful of
others that were kept because installers still called them.

On this desktop the command line is not a memory. Start - Programs - MS-DOS
Prompt opens a real window with a real shell in it, on a real pseudo
terminal, with your own HOME and PATH. It needs administrator rights, and
the refusal, if you do not have them, is shown in the status line at the
bottom of the screen.

What is in that window is whatever the machine has: bash, ls, git, and the
runtime this desktop is running inside. You can, from there, look at the
files that make the desktop you are looking at. That was possible in 1995
too, in the sense that you could open C:\WINDOWS in a DOS box, and about as
advisable.

THE ONES WORTH REMEMBERING
--------------------------

  DELTREE     Removed a directory and everything under it, without asking
              twice, at a time when there was no Recycle Bin for it to miss.

  SCANDISK    Checked the disk in a blue screen made of text, found a lost
              cluster, and asked whether to save it as a file you would
              never open.

  DEFRAG      Coloured squares, forty minutes, and the only screensaver
              anybody actually watched.

  EDIT        A text editor with a blue background and a menu bar, which
              booted faster than any editor since and lost nothing by it.
